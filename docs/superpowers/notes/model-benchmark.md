## 실행 메모

- 모델 파일: 3개 모델 모두 `ggml-org/gemma-4-*-it-GGUF` 저장소에는 Q4_K_M이 없어(Q4_0/Q8_0/BF16만 제공) `unsloth/gemma-4-{E2B,E4B,12B}-it-GGUF` 저장소의 `*-Q4_K_M.gguf` + `mmproj-F16.gguf`를 사용했다.
- `--ctx-size` 기본값(8192)으로 모든 조합이 VRAM 부족 없이 완료했다. gemma-4-12b 텍스트/이미지(no-think) 실행 시 최대 VRAM 사용량이 10.6~11.0GB로 12GB 카드의 한계에 근접했다.
- no-think 기준으로는 이미지 참고를 추가해도 평균 LLM 시간이 텍스트 전용 대비 소폭(약 0.1~0.3s/페이지) 늘어나는 정도였다. thinking 모드에서는 모델별로 이미지 방식이 텍스트 방식보다 빠르거나 느리거나 들쑥날쑥했는데, 이는 thinking 토큰 생성 길이의 변동성이 커서 나타난 잡음으로 보인다.
